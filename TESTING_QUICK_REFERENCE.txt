---------------------------------------------------------------------
4) Break-the-glass end-to-end test
---------------------------------------------------------------------
Scenario:
- Login as docteur@chu.fr
- Open patient 2024-016 (not assigned)
- Submit emergency access justification

Expected UI behavior:
- Initial patient access is denied and redirects to break-the-glass form.
- Justification shorter than 10 chars is rejected.
- Valid justification grants temporary access (30 minutes).
- Patient page becomes accessible after submission.

Database checks after a successful request:
1) Active break-the-glass record exists
   docker compose exec database psql -U app -d app -c "SELECT u.email, p.file_number, b.accessed_at, b.expires_at, b.reviewed FROM break_the_glass_access b JOIN \"user\" u ON u.id = b.user_id JOIN patient p ON p.id = b.patient_id WHERE u.email = 'docteur@chu.fr' AND p.file_number = '2024-016' ORDER BY b.accessed_at DESC LIMIT 1;"

2) Audit log contains break_the_glass action
   docker compose exec database psql -U app -d app -c "SELECT created_at, user_identifier, action, entity_type, entity_id, route_name FROM audit_log WHERE action = 'break_the_glass' AND user_identifier = 'docteur@chu.fr' ORDER BY created_at DESC LIMIT 5;"

Expected result:
- One recent row in break_the_glass_access for docteur@chu.fr + 2024-016.
- expires_at about 30 minutes after accessed_at.
- One recent audit_log row with action = break_the_glass.

6) Useful helper commands
---------------------------------------------------------------------
Find patient ID from file number:
  docker compose exec database psql -U app -d app -c "SELECT id, file_number FROM patient WHERE file_number IN ('2024-001','2024-016','2024-031','2024-050') ORDER BY file_number;"

Count active break-the-glass entries for docteur@chu.fr:
  docker compose exec database psql -U app -d app -c "SELECT COUNT(*) AS active_btg FROM break_the_glass_access b JOIN \"user\" u ON u.id = b.user_id WHERE u.email = 'docteur@chu.fr' AND b.expires_at > NOW();"

List latest access records for docteur@chu.fr:
  docker compose exec database psql -U app -d app -c "SELECT p.file_number, pa.access_level, pa.granted_at FROM patient_access pa JOIN \"user\" u ON u.id = pa.user_id JOIN patient p ON p.id = pa.patient_id WHERE u.email = 'docteur@chu.fr' ORDER BY p.file_number;"
